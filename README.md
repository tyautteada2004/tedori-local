# Tedori（ローカル版）

家計とシフトを管理して、**この先いくら使えるか**を見るためのアプリです。

**→ https://tyautteada2004.github.io/tedori-local/**

スマホのブラウザで開いて、**ホーム画面に追加**して使ってください。

---

## ⚠️ 最初に読んでください

### データはあなたの端末の中だけにあります

サーバーに送られません。作った人にも見えません。その代わり、

- **ブラウザのサイトデータを消すと、記録も消えます**
- **端末を変えても引き継がれません**

アプリの中に「書き出す」があります。**ときどき書き出してファイルを
どこかに保存してください。** それが唯一の控えです。

### iPhone の人は「ホーム画面に追加」が必須です

Safari は、ホーム画面に追加していないサイトのデータを
**7 日間使わないと消すこと**があります。

1. Safari で上のリンクを開く
2. 下の共有ボタン → 「ホーム画面に追加」
3. 以後はホーム画面のアイコンから開く

### ⚠️ 記録を始める前に追加してください

iPhone では、**ホーム画面のアプリと Safari は別々にデータを持ちます。**
Safari で先に記録すると、ホーム画面版から見えないことがあります。

**追加してから、ホーム画面のアイコンで開いて使いはじめてください。**

（追加すると「消えにくくする設定」は自動で有効になります。
手で押す必要はありません。うまくいったかは「設定」→「保存領域」で確認できます。）

---

## 使いはじめ

1. **「設定」→「口座」** から、現金や銀行口座を 1 つ登録する
   （初期残高もここで入れます）
2. 右下の **「＋ 入力」** から支出や収入を記帳する
3. アルバイトがあるなら **「設定」→「勤務先」** に時給を登録すると、
   シフトから給料を計算します
4. 家賃やサブスクは **「設定」→「固定収支」** に入れると、毎月自動で記録されます

「ホーム」に、今日から先の残高の見込みが出ます。
**いちばん少なくなる日といくらか**が分かるので、そこを見て使ってください。

---

## 分かっている制限

- **日本国内向けです。** 円のみ、日本の祝日のみ。
- **端末間の同期はありません。** 移すときは「書き出す」→「取り込む」。
- 通知はありません。
